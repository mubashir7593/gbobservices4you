# LinkForge IT / gbobservices4you

Static HTML/CSS/Vanilla JS website.

## Required setup
1. Open `js/script.js`.
2. Replace `PASTE_YOUR_GOOGLE_SHEET_CSV_LINK_HERE` with your published Google Sheet CSV URL.
3. Replace `PASTE_YOUR_WHATSAPP_NUMBER_HERE` with your WhatsApp number including country code.
4. Open `contact.html` and replace `PASTE_YOUR_FORMSPREE_URL_HERE` with your Formspree endpoint.
5. Replace the example canonical URL in each HTML file with your real domain.
6. Add your real Google Analytics and Google Ads conversion snippets where marked in each `<head>`.

## Google Sheet columns
Recommended headers:
Website, Niche, DA, Country, Price, TAT

The JavaScript also accepts common variants such as URL, Domain Authority, and Turnaround Time.
